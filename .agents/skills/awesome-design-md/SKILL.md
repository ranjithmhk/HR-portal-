# Awesome DESIGN.md

A comprehensive library of real-world `DESIGN.md` design system files extracted from top developer-focused and consumer websites.

## Usage

When designing or refining UI components, views, or entire apps:
1. Identify the aesthetic target (e.g., Linear for high-density dark/light modern productivity, Stripe for crisp financial/enterprise clarity, Apple for fluid human interface elegance, Airbnb for inviting hospitality/community).
2. Browse reference design systems in `./references/design-md/<brand>/DESIGN.md`.
3. Extract tokens, spacing curves, typography scales, card borders, elevation, button hierarchy, and micro-interactions.
4. Apply the design principles to the application's Tailwind / CSS styling.
